# Liza Veiga - Opera Singer Website

A beautiful, modern website for Portuguese opera singer Liza Veiga, featuring three artistic personas: Cyber Diva, Diva Rock, and Madre Diva.

## Features

- 🌍 **Trilingual Support**: English (EN), Portuguese (PT), and French (FR)
- 📱 **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- 🎭 **Artistic Personas**: Showcasing three distinct artistic identities
- 🖼️ **Image Gallery**: Interactive gallery with zoom functionality
- 🎥 **Video Section**: Promotional videos embedded from YouTube
- ✨ **Modern Design**: Elegant typography and smooth animations

## Technologies

- Pure HTML5, CSS3, and JavaScript (Vanilla JS)
- No frameworks or dependencies required
- Modern CSS Grid and Flexbox layouts
- Intersection Observer API for scroll animations

## Local Development

To run the site locally:

1. Clone the repository:
```bash
git clone https://github.com/pfigueiredo/lizaveiga.git
cd lizaveiga
```

2. Serve the site using a local server (choose one):

**Using Python:**
```bash
python -m http.server 8000
```

**Using Node.js (serve):**
```bash
npx serve -s . -l 3000
```

3. Open your browser and navigate to:
   - `http://localhost:8000` (Python) or
   - `http://localhost:3000` (Node.js)
